# Calendarize

<img src="./resources/img/calendarize-logo.png" style="max-width: 600px; width: 100%;">

> **This is the [Bearded Ginger Designs](https://github.com/beardedgingerdesigns/calendarize) fork of [`unionco/calendarize`](https://github.com/unionco/calendarize), adding Craft 5 support (3.0.0).** Upstream 2.0.0 supports Craft 4. The plugin API, Twig variables, and the `craft_calendarize` data shape are unchanged, so existing Craft 4 data carries over without a migration.

## Overview

This plugin adds a calendarize field type that provides an interface to have repeating dates just like on a calendar interface. Repeat daily, weekly, and monthly with multiple other configurations per repeat type. Also comes with the ability add exception dates.
